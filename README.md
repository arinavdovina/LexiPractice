# LexiPractice — конструктор промптов для закрепления лексики

Готовый локальный HTML-конструктор для преподавателей иностранных языков. Он не генерирует учебный материал сам, а собирает параметры и создаёт подробный методически выверенный промпт для ChatGPT/Claude.

## Что внутри

- Анкета: язык, возраст, CEFR-уровень, формат занятия и длительность.
- Поле для списка уже изученной лексики.
- Настройки цели, количества пунктов, ответов, типа материала и дизайна.
- Автоматический контроль позиций правильных ответов: равномерное распределение, отсутствие шаблонов и качественные дистракторы.
- **650 форматов**: 13 методических категорий × 50 механик/вариантов.
- Форматы не привязаны к темам. Это именно механики заданий: сопоставление, извлечение, коллокации, контекст, редактирование, говорение, игры, самопроверка и т. д.
- Поиск, фильтры, случайный подходящий формат.
- Один выбранный формат на один промпт, чтобы механика не распадалась на случайный набор упражнений.
- История, отметка использованных форматов, экспорт и импорт настроек.
- Копирование и скачивание готового промпта.
- `localStorage`: данные остаются только в браузере пользователя.
- Никаких внешних библиотек и сервера.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` двойным кликом.
3. Заполните анкету, вставьте лексику, выберите формат и нажмите «Собрать промпт».

## Структура файлов

- `index.html` — интерфейс.
- `styles.css` — адаптивный дизайн.
- `formats.js` — полный каталог из 650 форматов.
- `app.js` — логика фильтров, выбора, генерации, истории и экспорта.

## Логика каталога

Каталог состоит из 13 категорий. В каждой категории — 10 базовых механик, каждая представлена в пяти самостоятельных вариантах организации:

1. Базовый раунд.
2. Матричная версия.
3. Правдоподобные ловушки.
4. Лестница сложности.
5. Индивидуальный + партнёрский раунд.

Итого: 13 × 10 × 5 = 650 карточек.

## Важное методическое решение

Конструктор просит модель создавать одно законченное задание в выбранной механике, а не смешивать несколько случайных упражнений. Промпт ограничивает новую лексику, контролирует сложность контекста, требует правдоподобные отвлекающие варианты и адаптацию к возрасту и уровню.
